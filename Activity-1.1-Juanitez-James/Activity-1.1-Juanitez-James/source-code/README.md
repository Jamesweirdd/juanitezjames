# Pangasinan Heritage Digital Showcase

## Run
1. Install Node.js 18+.
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local address shown by Next.js.

## Build
Run `npm run build`. The static output is generated for deployment.

- atoms/
